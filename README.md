# The Krampus Mod

The Krampus Mod is a Minecraft mod that adds a festive twist to your game by introducing a Krampus boss with a health bar, special attacks, and a unique appearance. This mod is perfect for players who want to add a touch of Christmas chaos to their Minecraft world. The Krampus is fully black with two horns and a tail, and wears a red Santa hat, making it a standout enemy in your game.

## Install

1. Download the mod from the GitHub repository or the EnderDevelopment marketplace.
2. Extract the downloaded file to your Minecraft mods folder. The path to this folder is typically `C:\Users\<YourUsername>\AppData\Roaming\.minecraft\mods` on Windows, or `~/Library/Application Support/minecraft/mods` on macOS, and `~/.minecraft/mods` on Linux.
3. Launch Minecraft and select the world where you want to use the mod.

## Use

1. Once the mod is installed, you can spawn the Krampus boss using the Krampus Spawn Egg, which can be obtained by crafting or finding it in chests.
2. The Krampus boss will appear in your world and start attacking players. It has a health bar that displays its current health status.
3. The Krampus boss has several special attacks, including a slam, present throw, and punch. These attacks can deal significant damage to players, so be prepared to defend yourself.
4. Defeating the Krampus boss will reward you with loot, which can be used to craft new items or upgrade your existing ones.
